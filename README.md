# File-Converter

# What is File Converter
A simple web app file converter, that can convert your file format into other files format, including video, audio, image and document.

This project contain some page such as
1. About page
- This page features a brief description of the File Converter and a video demonstrating how to use the website, and there is also a second slide on this page which explains the advantages of this web app.

2. Convert Page 
- The primary function of this website is to convert files from one format to another. Also, You can upload files into it and then download the converted results.

3. Help Page
- This page design to be user support form for issue reporting. Users can describe their technichal problems and the system will generate a support email directed to the developer using the mailto. 

4. Footer 
- Positioned at the bottom of the application, providing quick navigation links to all avaible file conversion tools (Video, Audio, Image, and Document converters). It also includes social media links for direct developer connection.

# Features 
1. Multi-Format Conversion
   - Including type format Video, Audio, Image and Document.
  
2. Problem Reporting
   - There is a dedicated page to help users depending on their own technical problems.


3. Fully Responsive
   - This website offers a user-friendly experience on mobile phones, laptops, and desktops.

# Tech Stack
1. Front end: React JS,
2. Back end: Node js,
3. Styling: Tailwind css,
4. Routing: React Router DOM
